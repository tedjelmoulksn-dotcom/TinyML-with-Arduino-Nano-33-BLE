# TinyML on Arduino Nano 33 BLE

Project roadmap for embedded classification on Arduino Nano 33 BLE. Two application tracks are explored: recognising IMU vibration patterns and classifying electronic components from images.

## Getting started

Read the overview to choose an application, then define the acquisition hardware, dataset and model evaluation procedure. The default branch is `test`.

## Project context

The repository currently contains planning material. Firmware, training code and trained models have not yet been added. The image track requires an external camera.
